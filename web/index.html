Ghostties runs every Claude Code session in one window — a sidebar of live agents, with status you can read at a glance.

macOS 13+, Apple Silicon. Currently in beta.

Fill the Context Window

Collect tokens before the ghosts evict them from context. Arrow keys or WASD once you're in — no death, no losing, just a full context window and a proper payoff for getting there.

Still Ghostty

Ghostties is a fork of ghostty-org/ghostty, not a rewrite — your config, themes and keybinds load unchanged, the terminal engine underneath is still upstream Ghostty, and the sidebar is an additional surface, not a replacement.
