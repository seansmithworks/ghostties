Motion — type-to-reveal
A 20ms stagger is what makes rows read as arriving, not as popping
Rows have no background to fade, so the only things animating are opacity and 3px of rise. At zero stagger three rows appearing together read as a single block flashing on. Offset them and the eye tracks a sequence, which is what tells you the list is a response to your typing.

Out is slower than in, and unstaggered. Arrival wants to feel responsive; departure wants to feel unhurried, or it reads as the list being yanked away. Staggering the exit draws attention to something leaving, which is the opposite of what a rest state wants.
Open decision: what reveals the list. If it is typing alone, a user who does not know what to type never sees a list at all — and since PR #155 removed the picker controls, the list is the only browse path left. Recommend ↓ reveals it too, at the same 90/20 stagger.
