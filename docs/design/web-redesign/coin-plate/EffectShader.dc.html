HOWA full-plate quad running one fragment shader: an exponential lamp falloff, a three-stop blackbody ramp from white through amber to red, per-channel offset for chromatic bleed, hash grain, and a breathing term on uTime.
COSTOne GL context, one draw call per frame at 416×578. Trivial for the GPU, but it holds a context open for the life of the page and runs a rAF loop forever.
RISKHighest of anything here. Context loss on a laptop switching GPUs, no output at all under a blocked or software renderer, and it defeats prefers-reduced-motion unless the loop is explicitly gated. Needs a real fallback, not a blank rectangle.
VERDICTOverkill for 104×144. Real bloom and real chromatic bleed, and at delivery size almost none of it survives. Worth it only if the plate is ever shown large — a hero, a case study, the 14s film.
