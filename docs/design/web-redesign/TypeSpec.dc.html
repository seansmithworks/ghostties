Ghostties keeps every Claude Code session in one macOS window. The sidebar tells you which agents are working and which are waiting on you, and gt list collects every task across every project into one view. It is a fork of Ghostty, so the terminal underneath is the one you already use.

house rules — do
  • Square status marks. Never circles or pills.
  • Block labels butted together, sharing one hairline.
  • Uppercase micro-labels at 0.2em tracking, 600 weight.
  • Numerals in Silkscreen wherever they are a score or a count.
house rules — do not
  • No Inter, Roboto or system sans. The loudest AI tell.
  • No rounded corners or drop shadows on chrome.
  • No gradient-glass cards, no left-border accent panels.
  • No Silkscreen paragraphs and none below 10px.
conformance — not yet true
  • 8 Round 2 boards still load Martian Mono where this spec says Archivo: Main, Anatomy, AppAnnotated, AppMasks, AppReplica, CastOfEight, PixelMorph, ScrollFocus.
  • On spec today: Snake, AppZoom, Decrypt, TypeGrotesk.
  • Fix when each board is next opened, not as one sweep — several are cut candidates.
