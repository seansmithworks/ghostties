Ghostties · cli/ package · audit 2026-10-10

gt & ghostties‑mcp

A small task system that lives in Markdown files. People use gt, agents use the MCP server, and the app watches the folder. The core is solid and well tested. Users can't install it, though, and nothing has shipped for it since May.

Verdict

Keep it, stop promoting it for now, and reposition the MCP server as the part that matters.

The interesting user is the agent, not the person. "Your agent can file and update tasks in your sidebar" is a story. A human-facing gt CLI that duplicates the sidebar isn't, and the name collides with Graphite's widely used gt CLI.

How it fits together

No socket, XPC or URL scheme. Everything goes through files.

Health

solidGhosttiesCore (frontmatter, task store, directory lookup) is shared with the app, and cross-surface tests check that the CLI, MCP and app agree on the file format. About 139 test cases in cli/Tests, run in CI.
blockedNot distributed. Neither binary is in the .app, the Homebrew cask, or the release workflow. install-gt.sh builds from source, hardcodes arm64, and skips ghostties-mcp.
brokenOnboarding's "Install gt" button only works from a repo checkout (OnboardingSheet.swift:176).
dormant74 commits since 2026-04-23. 47 of them landed in April, and Sources/gt and Sources/ghostties-mcp haven't changed since 2026-05-18. Recent cli/ commits are composer-parser work.
driftsmoke-mcp.sh expects 11 tools (there are 12). TESTING.md says 110 tests. A test class the comments mention doesn't exist. MCP tests skip silently when the binary isn't built.
usageOne recorded real run (SESSION_NOTES, 23 Aug): 41 Linear issues synced, but ghostties-mcp wasn't on PATH and the build was stale. It was driven by hand over raw JSON-RPC.
riskAtomic writes but no locking: the app, gt and an agent writing at the same moment can clobber each other.

Testing gaps to close first

  • Make MCP protocol tests fail rather than skip in CI when the binary is missing.
  • Tests for set_task_fields and write_session_notes beyond the tools/list check.
