## 1. The problem

Running one coding agent is fine. Running five is a mess of terminal windows where you can't tell which one is waiting on you.

Ghostties puts every session in one window, grouped by project, with status you can read at a glance. Free, for the Mac.

ghostties.org

Attach: README demo GIF.

## 2. Status at a glance

Every session row in Ghostties says what its agent is doing: a spinner while it works, a ? when it needs you, a check when it's done, a cross on an error.

Hover a row to see what it wants to run. Codex needs no setup; Claude Code needs a one time hook setup.

ghostties.org

## 3. Themes (beta 27)

New in Ghostties beta 27: pick a theme from Settings, or type "theme" in Cmd+T and arrow through a live preview of the whole window.

The sidebar and canvas now follow your terminal theme, not just the terminal.

## 4. Still Ghostty

Ghostties is a fork of Ghostty, not a rewrite. Your config, themes and keybindings load unchanged, and the terminal underneath is upstream's.

What it adds is a sidebar for running Claude Code and Codex side by side.

ghostties.org

## 5. The sidebar gets out of the way (beta 27)

Ghostties beta 27: with the sidebar closed, rest on the window's left edge and the full sidebar slides back in, moving the terminal over. Move away and it closes.

Free and open source, macOS 13 or later on Apple Silicon.
