# Ghostties beta 27

Built from the `## [Unreleased]` draft in `CHANGELOG.md`. Update both together.

## Copy

**Ghostties beta 27 is out.** Themes, a Settings window, and a quieter sidebar.

**Settings, finally.** Cmd+, opens a real Settings window with General and Appearance panes. Open Config File is always one click away, and Ghostties never writes your config file.

**Pick a theme, watch it live.** Browse themes as a grid in Settings, with separate Light and Dark picks, or type "theme" in Cmd+T and move through the grid to preview the whole window. Return keeps it; Esc puts the old one back. A System, Light or Dark switch sits alongside.

**The whole window follows your theme.** Pick something other than the Ghostties theme and the sidebar, canvas and toolbar pills take their colors from it, with sidebar text kept readable.

**A new default look.** Ghostties Light and Ghostties Dark are now the default terminal theme, and dark mode is darker, with a softer card shadow.

**A quieter selected row.** The selected session is a thin outline over a tint that crossfades between rows, and the project you're working in sits on a glass card.

**A closed sidebar slides out.** Rest on the window's left edge and the full sidebar slides in and moves the terminal over. Move away and it closes again.

**Fixes.** Closing the embedded browser no longer closes the window; it asks first and closes only the browser. Cmd+T then Return opens a Shell, even when Browser is the project's default. The terminal card keeps its shadow after a light or dark switch.

Already installed? Ghostties updates itself. New here? Get it at ghostties.org.
