# Product Hunt

## Name

Ghostties

## Tagline (60 characters max)

One window for every coding agent you're running

## Description (260 characters max)

A free Mac terminal for running several coding agents at once. Every Claude Code and Codex session in one window, grouped by project, with status you can read at a glance. Built on Ghostty, so your config and keybindings carry over.

## First comment

Hey Product Hunt, I'm Sean.

I built Ghostties because running five agents meant five terminal windows and no idea which one needed me.

It's Ghostty's terminal with a workspace layer on top: a project sidebar, a status glyph on every session, hover cards that show what an agent wants to run, and one composer (Cmd+T) to start or resume Shell, Claude Code, Codex and Browser sessions. Agents can file their own tasks through the gt CLI or the MCP server.

It's free, open source and in beta, for macOS 13 or later on Apple Silicon. I'd love to hear what you'd want it to show you next.
