At-the-desk capture checklist

Every step is Sean, at the machine. Screen-capture permission is granted to the terminal, not the app, and can deny silently even when visibly on — the fix needs a relaunch that would kill this session.

  1. Set the scene by hand: sessions, projects, mode, per shot.
  2. screencapture -D 2 from a real Terminal window — the delay lets you click the target window first.
  3. Save to images/marketing/, named to match the asset table (e.g. hero-dark.png).
  4. App icon: export 1024×1024 from the existing source in images/ — no new capture.
  5. Hand the PNGs off; the site/web build from there can be delegated.

Yours to decide — three forks

  1. Is terracotta still the Ghostties brand color at all? This is Sean's open call, not mine — feedback_terracotta-not-brand-color.md records him mulling it on 2026-06-23 and explicitly not resolving it. One prior decision already narrows it: terracotta is out of the status-dot semaphore, permanently. What's undecided is whether it stays the general brand accent (pins, callouts, launch banner) or gets replaced there too.
    If a strawman is useful: keep it as brand-accent chrome for now — nothing else in the palette currently fills that role, and swapping it is a bigger design pass than this plan should trigger. But treat this as flagged, not decided.
  2. Does the reference site ever go public?
    Strawman: no, stays local-only. It documents internal detail — dynamic-color approximations, a known contrast failure, Swift token names — that reads as unfinished to an outside visitor.
    Alternative: a curated public subset on ghostties.org later, if there's ever a concrete reason (press kit, etc.).
  3. Do the ghost sequences animate?
    Strawman: static pixel-grid renders only, v1. Motion capture is more desk time, and 24 distinct characters are already legible frozen.
    Alternative: screen-record idle/walk loops per character — nicer, five more capture sessions for a page whose job is "what are the 24 characters," not "how do they move."

Not a decision, just so it isn't re-litigated: the reference site is never imported, linked, or wired into either codebase. It's a document that happens to be HTML.
