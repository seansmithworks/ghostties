# Findings ledger: session-row-status

51 rows: 28 from the generalist refutation (`refutation.md`, G-F1 to G-F28, verdict rethink), 22 from the AppKit/macOS-systems refutation (`refutation-appkit.md`, A-F1 to A-F22, verdict rethink), plus one row for the change both refuters named as their single most important. Neither refuter was the drafter. Evidence unedited on disk.

**"Superseded"** means the finding is about the dead join (launcher-UUID argv, or `~/.claude/sessions/<pid>.json`) and the new foundation makes it moot, not that it was wrong. Those findings were correct; the thing they were correct about no longer exists in the plan.

## Structural decisions taken from the gate

**D-A. The join is one environment variable, not a process-table read.** `GHOSTTIES_SESSION_ID` in `config.environmentVariables` at `SessionCoordinator.swift:249`. Environment survives `exec`, covers shell templates (which never had a command and therefore never had a launcher script), and covers a `claude` typed into a surface an hour later. Deletes the `launchBanner` gate, the ancestor walk, the launcher lifecycle coupling, and the entitlements question in one move. G-F8 and A-F15, first halves.

**D-B. The status source is Claude Code hooks, not a status file.** All seven states plus the prompt-shape payload decision 5 needs, written by the agent itself, delivered to a script that is Claude's own child and therefore already holds the environment. G-F9 and G-F28. This is what moves Phase 3 (todos) and Phase 4 (Approve) from "parked" to "scheduled", which is the half of the request Sean led with.

**D-C. The read-back half of both refuters' fix is rejected on measurement.** See the final row.

**D-D. No abstain rule.** A row with no state file keeps today's heuristics exactly. G-F19 and G-F6: as written the rule was a regression switch that also contradicted the draft's own mapping section.

**D-E. Every write is temp-file-plus-rename.** G-F2, G-F24, A-F4. A directory vnode source fires on entry changes, not in-place writes; the draft's watcher would have frozen at first read.
